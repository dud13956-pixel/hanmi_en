# FabTalk · 반도체 영업 전화영어 (독립 실행 버전)

Claude 앱 밖에서, 내 주소로 올려서 쓰는 버전입니다. Claude API 키가 필요하고, 쓴 만큼 API 크레딧이 차감됩니다.
(API 키 없이 쓰려면 Claude에 올린 아티팩트 링크를 안드로이드 **크롬**에서 여세요.)

## 1. 무료로 올리기 (GitHub Pages, 약 5분)
1. github.com 가입 → 오른쪽 위 **+** → **New repository** → 이름 `fabtalk` → **Public** → Create
2. **uploading an existing file** 클릭 → 이 폴더의 파일 6개(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, README.md)를 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings → Pages** → Branch를 `main` / `(root)`로 선택 → **Save**
4. 1~2분 뒤 `https://<내아이디>.github.io/fabtalk/` 주소가 생깁니다.

## 2. 안드로이드 폰에 설치
1. 크롬으로 위 주소 열기 → 메뉴(⋮) → **홈 화면에 추가** (또는 **앱 설치**)
2. 처음 마이크를 누를 때 **허용** 선택

## 2-1. 아이폰에서 쓰기
- **Safari**로 주소를 열면 앱 안의 마이크 버튼으로 바로 말할 수 있어요. (설정 > Siri가 켜져 있어야 함)
- 처음 마이크를 누를 때 **허용**을 선택하세요. 거부했다면 설정 > Safari > 마이크에서 바꿀 수 있어요.
- **홈 화면에 추가**한 앱, 아이폰용 크롬, 카카오톡 링크로 열면 아이폰이 앱 안 음성 인식을 막아요.
  이때는 입력창을 누르고 키보드를 **English**로 바꾼 뒤 **키보드의 마이크 아이콘**(받아쓰기)으로 말하면 돼요. 앱이 자동으로 안내해요.
- AI 목소리가 작게 들리면 이어폰을 쓰거나 볼륨을 올려 주세요(마이크 사용 뒤 아이폰이 소리를 작게 내는 경우가 있어요).

## 3. API 키 넣기
1. platform.claude.com 가입 → Settings > Billing에서 크레딧 충전 (자동 충전은 끄기 권장)
2. API Keys에서 키 생성 → 앱의 **설정 → Claude API 키**에 붙여넣기 → **연결 테스트**
3. 모델은 **Haiku 5.5(권장)**. 10~15분 통화 1회에 보통 1센트 안팎입니다(추정).

## 알아둘 점
- 음성 인식은 크롬 기능이라 인터넷이 필요합니다. 시끄러운 곳에서는 키보드 버튼으로 입력하세요.
- API 키와 학습 기록은 이 폰의 브라우저에만 저장됩니다. 설정 → **백업 복사**로 가끔 백업하세요.
- 키는 본인 폰에서만 쓰세요. 이 주소를 남과 공유해도 키는 공유되지 않지만, 남의 폰에 키를 입력하지 마세요.
- 영업 기밀(실제 고객명, 견적 금액)은 대화에 넣지 않는 것을 권장합니다.
